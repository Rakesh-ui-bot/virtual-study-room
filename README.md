# 🌌 Nexus - Virtual Study Room

Nexus is a highly attractive, futuristic virtual study room web application designed to boost productivity. Built with Vanilla JavaScript, HTML, and CSS, it features a stunning glassmorphism UI, a dynamic background, and modular, clean code.

## 🚀 Features

*   **Pomodoro Timer Widget**: A fully functional timer with a circular progress SVG animation. Supports Pomodoro (25m), Short Break (5m), and Long Break (15m) modes.
*   **To-Do List Widget**: Add, complete, and delete tasks. Integrates seamlessly with productivity analytics.
*   **Ambient Music Player Widget**: Features volume controls, previous/next buttons, and plays ambient tracks directly in the browser.
*   **Productivity Analytics Widget**: Automatically tracks the number of Pomodoro sessions completed, total focus time, and tasks checked off.
*   **Dark/Light Mode**: Toggles between a bright, futuristic daylight study room and a neon cyberpunk nighttime study room. 
*   **Persistent Storage**: Uses LocalStorage to save your theme preferences, tasks, and analytics.
*   **Modern Dashboard UI**: A fully responsive CSS Grid layout utilizing sleek glass panels with hover animations and micro-interactions.

## 💻 Tech Stack

*   HTML5
*   CSS3 (Variables, Grid, Glassmorphism, Animations)
*   Vanilla JavaScript (ES Modules)
*   Vite (for local development and bundling)

## 🛠️ Installation & Setup

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd virtual-study-room
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
